# Контент-агент канала Cucumber Game

Полные редакционные правила находятся в `AGENT.md`. Прочитай его целиком перед работой.

В автоматическом запуске разрешена только подготовка черновика:

- сначала дедуп и проверка `runtime_input.json`;
- затем выбор первого достойного тира;
- факты только из открытых источников;
- результат только по `draft.schema.json`;
- не менять файлы, не выполнять Git и не отправлять публикации.

Запись состояния, push и отправку выполняет отдельный проверяющий раннер. Нет достойного повода — вернуть СКИП.

Окружение для баннера: Python 3, Pillow, шрифты DejaVu или Liberation.
